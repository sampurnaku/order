Cek Order

PDF Instruction Sheet (IS) jadi order, satu file Excel per plant jadi jumlah stock fresh dan stock grade yang sudah didapat.

Versi 10-11-2026, data dipisah per plant LJB dan LJK, satu file Excel stock per plant

Cukup satu file Excel per plant (LJB atau LJK), bisa memilih dua file sekaligus. Plant dikenali dari nama file, kalau tidak ada LJB atau LJK di nama file, ditanyakan. Isi kolom Jenis Proses yang memuat kata FRESH menjadi stock fresh, sisanya menjadi stock grade. Unggahan baru mengganti semua data stock plant itu, data plant lain tidak berubah.

Cadangan data

Simpan semua order dari plant LJB dan LJK (termasuk tanda close) ke satu file untuk pindah HP atau sebagai pengaman. Data stock tidak ikut disimpan, karena bisa diunggah ulang dari Excel. Saat impor, semua order di aplikasi ini diganti dengan isi cadangan, tidak ditambahkan.

Kotak ini mencari di semua kolom sekaligus, beberapa kata dipisah spasi. Untuk mempersempit per kolom, pakai filter di bawah.
