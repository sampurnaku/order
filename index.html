Cek Order

PDF Instruction Sheet (IS) jadi order, Excel jadi jumlah stock fresh yang sudah didapat.

Versi 06-11-2026, stock fresh punya CLR dan total pcs

Bisa pilih beberapa file sekaligus. Kalau sudah ada file hasil sebelumnya, cara penggabungannya ditanyakan satu kali untuk semua file.

Pilih satu atau beberapa file Detail Barang By Jenis Proses untuk stock grade, misalnya ZB STOCK atau BS ZB. Nama di daftar mengikuti judul di dalam file Excel. Jenis yang sama (misalnya ZB STOCK 58) diganti dengan file terbaru, jenis baru ditambahkan.

Cadangan data

Simpan semua order, hasil, dan stock grade ke satu file untuk pindah HP atau sebagai pengaman. Saat impor, semua data di aplikasi ini diganti dengan isi cadangan, tidak ditambahkan.

Kotak ini mencari di semua kolom sekaligus, beberapa kata dipisah spasi. Untuk mempersempit per kolom, pakai filter di bawah.
